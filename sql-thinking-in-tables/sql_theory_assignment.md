1)Explain why databases are important in real-world AI systems. Mention examples of the types of data typically stored in databases and why structured storage is necessary.
In real-world applications, data is constantly being created and updated. Because of this, storing data in simple files like Excel sheets or CSV files is not practical for large systems. Databases help store, organize, and manage large amounts of data efficiently so that applications and AI models can access it whenever needed.AI systems especially depend on large datasets for training and making predictions. Databases make it easier to store this data in a structured way and retrieve it quickly using queries.For example, in an online shopping platform, the database might store data about users, products, and orders. An AI model can then analyze this data to recommend products to users based on their past purchases.

2)Describe the relational database mental model. Explain what tables, rows, and columns represent, and why each table should represent a single entity.
Relational databases organize data in the form of tables. When working with relational databases, it helps to think of data as a collection of tables where each table represents a specific type of information.A table contains rows and columns.Each table should represent only one type of entity. This is considered good database design because mixing different types of data in one table can make the system confusing and harder to manage.Rows represent individual records in the table. Each row contains data about one instance of the entity.Columns represent the attributes or properties of the entity. They define what kind of information is stored.

3)Explain the concept of a primary key. Describe why primary keys must be unique and non-null, and how they help identify records in a table.
A primary key is a column in a table that uniquely identifies each record.A primary key cannot contain NULL values because every record must have an identifier.Primary keys are important because they make it easy to identify and retrieve a specific record from the database.hey also help maintain data integrity by preventing duplicate entries.

4)Explain what a database schema is. Describe what information a schema defines and why schemas are important for maintaining consistent data structure.
A database schema is basically the structure or blueprint of a database. It defines how the database is organized.The schema includes information such as Table names,Column names, Data types of columns, Primary keys, Foreign keys, Constraints.Schemas are important because they help maintain consistency in the database. They ensure that all data follows the same structure and rules.Without a schema, data might be stored in inconsistent formats, which could lead to errors, confusion, and poor data quality.Schemas also help developers understand how the database is organized and make it easier to maintain the system in the long term.

5)Explain how relationships between tables work in relational databases. Describe the role of foreign keys and how tables such as users and orders can be connected.
In most applications, data is not stored in just one table. Instead, it is divided into multiple tables that are connected to each other through relationships.These relationships are created using foreign keys.A foreign key is a column in one table that refers to the primary key of another table. This allows the database to connect related data across tables.Using relationships helps reduce duplication of data and keeps the database organized. It also allows us to combine information from multiple tables using SQL queries such as joins.
